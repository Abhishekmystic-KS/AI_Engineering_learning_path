BEGINNER COMMANDS GUIDE

Use these files as a small daily reference. You do not need to memorize every command. Learn the common ones first and use help pages when needed.

FILES

1. basic-and-python-commands.txt
   Terminal navigation, virtual environments, packages, and tests.

2. git-and-team-commands.txt
   The commands used to work safely with teammates and GitHub.

3. docker-and-production-commands.txt
   Basic commands for packaging, running, checking, and stopping services.

4. common-command-failures.txt
   Frequent errors and simple ways to solve them.

GOOD HABIT

Before running an unfamiliar command, understand what it changes. Be especially careful with commands that delete files, change production data, or affect many users.
